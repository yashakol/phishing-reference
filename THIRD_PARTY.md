# Внешние данные

Для `submission_reference` использован набор:

Subhash Ariyadasa; Shantha Fernando; Subha Fernando. "Phishing Websites Dataset". Mendeley Data, Version 1. DOI: `10.17632/n96ncsr5g4.1`.

- [Страница набора и сведения об авторах](https://data.mendeley.com/datasets/n96ncsr5g4/1)
- [DOI](https://doi.org/10.17632/n96ncsr5g4.1)
- Лицензия, указанная на странице набора: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Использован файл `index.sql` без изменения его байтов; локальное имя - `mendeley_index.sql`. Из него извлечены пары URL/метка. Одинаковые записи объединены, URL с конфликтующими метками исключены, затем выполнено точное сопоставление. Это обработка исходных данных авторами данного решения; авторы набора не подтверждали и не поддерживали решение.

Файл SQL включен в `payload/` и восстанавливается без изменения байтов. HTML внешнего набора не включен. Train и test организатора также входят в поставку; они включены для воспроизведения решения организатором. Допустимость использования опубликованных тестовых меток организатором отдельно не подтверждена.

Сведения о сторонних библиотеках приведены в `requirements.txt` соответствующего варианта. Этот файл закрепляет версии окружения, но не заменяет лицензии самих библиотек.
