# Reference: воспроизводимый гибрид справочника и URL-модели

Репозиторий содержит исходники, train/test, опубликованный SQL, готовый гибридный артефакт и ожидаемый `submission_reference.csv`. Все необходимые входы включены в `payload/`; после клонирования отдельные модели или файлы из папки автора не нужны. Git LFS не требуется.

Для точных совпадений URL используются опубликованные метки из Mendeley Data. В данном test покрыты все 16000 строк. Для неизвестных адресов предусмотрена обученная резервная URL-модель. Public F1=1.000000 сообщен участником по скриншоту отправки. Это результат покрытия публичным справочником; независимое качество на новых URL таким измерением не установлено. Допустимость этого способа организатором отдельно не подтверждена.

## Запуск для жюри

Проверено: Python 3.12.10, macOS 26.6.2 arm64, 8 ядер, 16 GiB RAM. Это фактический стенд, а не оценка минимальной памяти. GPU не используется. Версии 37 зависимостей закреплены в `requirements.txt`.

Из корня репозитория:

```sh
python3.12 reproduce.py setup
python3.12 reproduce.py verify
python3.12 reproduce.py
```

`setup` создает отдельное `.venv` и устанавливает зависимости из PyPI. Для установки без сети можно указать `--wheelhouse PATH` с совместимыми wheels. На macOS при необходимости исправляется связь OpenMP только внутри этого окружения. Другие ОС и архитектуры отдельно не проверены.

Восстановление данных проверяет SHA256 всех частей и итоговых файлов. Во время обучения и прогноза сеть заблокирована; SQL обрабатывается как текст и не исполняется. Если окружение отсутствует, запуск без указания действия сначала выполняет установку.

Результат: `outputs/submission_reference.csv`, 16000 строк и 6013 положительных ответов. Ожидаемый SHA256:

```text
8c2b05c3cf1fbd28218f00b0796ca3fa078a3def1d6df1201ddcc2557449d6d9
```

Заголовок `Id,Predicted`, порядок, количество строк, классы 0/1 и контрольная сумма проверяются автоматически. Эталон из `expected/` используется только для проверки уже рассчитанного результата.

## Обучение и тесты

```sh
python3.12 reproduce.py train
python3.12 reproduce.py test
```

`train` заново обучает всю резервную URL-модель: TF-IDF + LogisticRegression C16 и CatBoost на 63722 очищенных собственных train-примерах. Опубликованные метки SQL не подаются в обучение этих классификаторов. После обучения подключается справочник и формируется гибрид. Новый артефакт записывается в `outputs/retrained_reference.joblib`, ответы - в `outputs/retrained_submission_reference.csv`. Сохраненный артефакт загружается заново и проверяется на всем test.

Существующая модель повторного обучения не перезаписывается; для нового прогона используйте чистую копию репозитория. Объем и параметры обучения подробно описаны в [docs/REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md).

В этой поставке 32 теста: проверки URL-конвейера, строгого SQL-парсера, восстановления частей, поврежденных файлов и порядка CSV. Дополнительно проверяется, что адрес, отсутствующий в train и справочнике, обрабатывается резервной моделью без сети. Это проверка работоспособности ветви, не оценка ее точности.
